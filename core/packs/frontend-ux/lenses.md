# frontend-ux: review lenses

Added to the eight base lenses:

- Accessibility: names, roles, focus order, contrast, keyboard paths.
- Design-system use: existing components and tokens used; no one-off
  copies of a component.
- Visual consistency: spacing, type and states match the rest of the app.
- State honesty: loading, empty, error and rollback states are shown and
  truthful.
