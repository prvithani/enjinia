# frontend-ux: requirements

User interfaces. Extra content:

- `UX-` user flows: who, starting where, doing what, ending where; the
  states they pass through (empty, loading, error, partial, done).
- `A11Y-` accessibility: keyboard use, screen reader names, contrast,
  focus, motion, to a stated standard (for example WCAG 2.2 AA).
- What the user sees when the server is slow, fails, or refuses.

Interview prompts that pass the "no design" test:
- Walk me through the last time a user did this: where did they start,
  what did they need to know, where did they get stuck?
- What must a user never lose, or never see?
- Which devices and assistive technology must work?
UX research needs real users; agents prepare and synthesize it, and the
input comes from the human.
