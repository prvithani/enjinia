# Requirements: notifications

- FR-1: The server can create a notification for one user, or for everyone with access to a subject. (source: ticket)
- FR-2: A user sees their unread notifications in an inbox and can mark each read. (source: ticket)
- FR-3: A notification that arrives while the app is open shows a toast. (source: ticket)
- FR-4: A family that redeploys itself or fails notifies the family's owners. (source: ticket)
- NFR-1: A notification reaches an open app within 5 seconds. (source: ticket)
- NG-1: Email or push delivery.
